# Contributing

Submit a pull request with an official project or documentation URL, a concise original description, an existing category (or rationale for a new one), and an access model. Avoid affiliate links, duplicate entries, unsupported pricing or license claims, and promotional rankings. Update both `data/catalog.json` and `README.md` and run `python3 -m unittest discover -s tests -v` before submission. Do not include credentials or personal information.
